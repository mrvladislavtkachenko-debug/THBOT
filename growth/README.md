# 🚀 THBOT Growth — автопилот роста на обычном токене

Никаких левых аккаунтов, API-доступов и риска бана. Обычный бот от [@BotFather](https://t.me/BotFather),
который после настройки работает сам.

## Что он делает автоматически

| Модуль | Как приводит людей |
|---|---|
| 📅 **Автопостинг** | Ты пересылаешь боту посты (текст/фото/видео) — он публикует их по расписанию, к каждому пришивает кнопку **«📤 Поделиться»** (вирусный охват) |
| 🎲 **Авторозыгрыши** | `/contest` → приз, срок, победители. Участие кнопкой, проверка подписки, автовыбор победителей, продление если никто не подписался. Розыгрыш — главный магнит для входа |
| 🔗 **UTM-ссылки** | `/link tiktok` → уникальная ссылка. Бот сам считает, сколько подписчиков пришло с тиктока, посева, ВП. Впервые видишь, что реально работает |
| 💬 **Живой чат** | Викторины и опросы по расписанию, приветствие новичков, капча от ботов, антиспам, топ активных недели. Живой чат удерживает и поднимает канал в поиске |
| 📊 **Отчёт** | Каждое утро: подписчики, динамика, входы по источникам, очередь постов |

## Запуск (10 минут)

### 1. Бот и права
1. [@BotFather](https://t.me/BotFather) → `/newbot` → токен.
2. Добавь бота в **админы канала**: права «публикация сообщений» + «пригласительные ссылки».
3. Если есть чат обсуждений — добавь туда же: «удаление сообщений» + «ограничение участников».
4. Узнай ID: [@userinfobot](https://t.me/userinfobot) (свой), перешли ему пост из канала (ID канала вида `-100...`), сообщение из чата (ID чата).

### 2. Настройка
```bash
cd growth
cp .env.example .env
nano .env   # BOT_TOKEN, CHANNEL_ID, CHANNEL_URL, CHAT_ID, ADMIN_IDS
cp quiz.txt.example quiz.txt       # по желанию, свои викторины
cp polls.txt.example polls.txt     # по желанию, свои опросы
pip install -r requirements.txt
python growth.py
```

### 3. Заполни очередь
Перешли боту в личку 10–20 постов (старые лучшие + новые). Проверь: `/queue`.
Дальше он публикует сам в 09:00 / 13:00 / 19:00.

### 4. Запусти первый розыгрыш
`/contest` → приз (например «Гайд за 500₽ бесплатно») → `72` → `1`.
Анонсируй розыгрыш везде, где можешь: статус, чаты, знакомые.

### 5. Разметь источники
`/link tiktok`, `/link posev_kanal`, `/link vp` — разные ссылки в разные места.
Через неделю `/sources` покажет, откуда идут люди. Нерабочее — отключаешь, рабочее — масштабируешь.

## Ежедневная рутина (5 минут вместо часов)

- Утром читаешь отчёт бота.
- Пересылаешь 1–3 поста в очередь (или раз в неделю пачку).
- Раз в неделю — новый `/contest`.

Всё остальное (постинг, викторины, капча, спам-чистка, подсчёт) — сам бот.

## Как ускорять рост (лестница)

1. **Неделя 1:** очередь 20+ постов, 1 розыгрыш, ссылки с метками везде.
2. **Неделя 2:** смотришь `/sources` — удваиваешь то, что дало входы.
3. **Неделя 3:** первый платный посев (пост в канале-доноре со ссылкой-меткой) — эффект замерит бот.
4. **Неделя 4:** еженедельный розыгрыш + топ чата с призом самому активному.

## Файлы

```
growth.py    — всё ядро
config.py    — настройки из .env
storage.py   — SQLite (очередь, конкурсы, входы, активность)
content.py   — парсинг викторин/опросов, кнопки «Поделиться»
keyboards.py — кнопки
texts.py     — все тексты (перепиши под себя)
quiz.txt / polls.txt — викторины и опросы (создай из .example)
```

## Если что-то не работает

- Посты не публикуются → бот не админ канала с правом постинга.
- `/link` ошибка → нужно право «пригласительные ссылки».
- Капча/бан не работают → нужно право «ограничение участников» в чате.
- Входы по ссылкам не считаются → ссылки должны быть созданы через `/link`, а не обычная ссылка-приглашение.
- Нет чата обсуждений — оставь `CHAT_ID` пустым, остальное продолжит работать.
