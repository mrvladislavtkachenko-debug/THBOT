# Редизайн выдачи: от «справки» к «рецензии»

> Гипотеза: текущий отчёт информативный, но сухой — он читается как выгрузка
> из базы. Хочется, чтобы сводку было **интересно читать и хотеться переслать**.
> Для этого отчёт должен быть не энциклопедией, а мнением живого рецензента,
> который за минуту даёт ответ и только потом — доказательства.

## 1. Принципы

1. **Решает за 10 секунд.** Первое «сообщение-карточка» отвечает на главный
   вопрос — «подписываться или нет и как читать» — до любых подробностей.
2. **Решительность вместо перечисления.** У отчёта есть точка зрения: именной
   тир («💎 Маст-хэв», «📻 Фоновый шум»), а не набор цифр без вывода.
3. **Конкретика вместо общих слов.** Слоган канала, фирменная фишка, реальная
   цитата голосом автора, ссылки на конкретные посты. Никаких «канал про
   маркетинг с полезными советами».
4. **История, а не метрики.** Цифры — это якоря правды, но запоминается сюжет:
   как канал менялся, что автор продаёт, на чём горит.
5. **Честность с острым углом.** Рекламу, взаимопиар и воду называем прямо,
   без политеса — за это боту и будут доверять.
6. **Две аудитории — одна выдача.** Подписчику — «читать/не читать и с чего
   начать»; автору канала — «что забрать себе и чего не делать».
7. **Телеграм-формат.** Сканируется с телефона: эмодзи-якоря, короткие абзацы,
   визуальные шкалы, 2 сообщения вместо простыни.

## 2. Тир вместо сухого балла

Индекс 0–100 считаем как сейчас (код), но показываем через запоминающийся тир:

| Балл | Тир | Что значит |
|---|---|---|
| 85–100 | 💎 **МАСТ-ХЭВ** | подписываться не глядя, читать целиком |
| 70–84 | 🟢 **КРЕПКИЙ ЭКСПЕРТ** | подписаться, читать выборочно |
| 50–69 | 🟡 **НА ЛЮБИТЕЛЯ** | польза есть, но надо фильтровать |
| 30–49 | 🟠 **ФОНОВЫЙ ШУМ** | можно не подписываться |
| 0–29 | 🔴 **МИМО** | реклама/копипаста/пустышка |

Тир назначает **код** по индексу (единообразие), а человеко-читаемое
объяснение — модель.

## 3. Новый формат (макет)

### Сообщение 1 — «Карточка канала» (ответ за 10 секунд)

```
📡 МОЛЯНОВ — разбор канала
🔗 @molyanov_blog · ~3,6 тыс. просмотров на пост
🗓 ~5 постов/нед · разобрано 100 постов

🟢 КРЕПКИЙ ЭКСПЕРТ · 74/100

«Полевой журнал практика про нейросети: автор показывает свои
 проекты вживую, а между делом продаёт клуб "Нейроцех"».

Полезное          ████████████░░  65%
Реклама/запуски   ██░░░░░░░░░░░░  12%
Репосты/шум       ████░░░░░░░░░░  23%
Вовлечённость     высокая (реакции есть даже на рекламе)

👉 Как читать: выборочно, лучшее — по ссылкам во втором сообщении
✅ Вам сюда, если вы делаете контент/продукт и внедряете нейросети в работу
🚫 Мимо, если бесит инфо-стиль и запуски продукта раз в месяц
```

### Сообщение 2 — «Разбор» (мясо для тех, кому интересно)

```
👤 АВТОР КАК ЧЕЛОВЕК
Практик, а не коуч: ведёт свои проекты (Chrome-расширения, SEO-статьи,
автоматизация на агентах) и показывает процесс с цифрами. Пишет как
объясняет коллеге за обедом — коротко, с матерком, без «вы».

🗣 Голос канала: «Лимитов Кодекса на это всё хватает. Клод бы ещё
   два часа назад сходил»
✨ Фирменная фишка: не «как заработать на ИИ», а «смотрите, что я
   вчера накрутил на агентах за вечер».

📈 ЧТО ПРОИСХОДИЛО (за последние недели)
Канал живёт в режиме запуска клуба: часть постов — анонсы лекций и
продажи членства (это те самые ~12%). Между запусками — плотный
личный контент про вайбкодинг. Просадки реакций — только на чистой
рекламе, органика держится ровно.

🌶️ ЧЕСТНО, БЕЗ ПОЛИТЕСА
Автор продаёт откровенно и не маскирует рекламу под пользу — это плюс.
Но примерно каждый третий пост так или иначе ведёт в «Нейроцех», а ещё
проскакивают взаимные подборки «залетайте к ребятам» — самое слабое
место ленты.

🧰 ЧТО ЗАБРАТЬ СЕБЕ (по-хорошему — своровать)
1. Формат «что я накрутил на нейронках за неделю» — живые скриншоты
   процесса собирают максимум реакций, потому что это анти-теория.
2. Портянка-анонс списком: 6 лекций с интригой в одном посте → t.me/…
3. Видео-мем с подписью «делился в комментах, решил и вам показать» —
   дёшево, даёт охваты и человечность.
🙅 Не воровать: мантру «купи клуб» в каждый третий пост.

🔥 3 ПОСТА, КОТОРЫЕ ОБЪЯСНЯЮТ КАНАЛ
• Манифест (о чём вообще канал) → t.me/…
• Лучший практический гайд → t.me/…
• Самый живой/вирусный → t.me/…
```

## 4. Что нового в полях синтеза (LLM)

Расширяем JSON-схему синтеза. Числа по-прежнему считает код, модель —
только смыслы и строго по предоставленным постам (без выдумок):

```json
{
  "tagline": "одна фраза-характеристика канала, едкая и точная",
  "reading_mode": "целиком | выборочно | только избранное | не читать",
  "for_you": "кому канал прям в касцию (1 предложение)",
  "not_for_you": "кому не зайдёт (1 предложение)",
  "persona": {
    "sketch": "автор как человек: кто, как пишет, какой темперамент",
    "signature": "фирменная фишка канала",
    "voice_quote": "ДОСЛОВНАЯ цитата из предоставленных постов, передающая голос"
  },
  "arc": "история за наблюдаемый период: запуски, смена тем, ритм",
  "hot_take": "один острый честный тезис, который заметил рецензент",
  "swipe_file": [
    {"format": "формат/практика, которую стоит забрать",
     "why_it_works": "почему работает, по реакциям/просмотрам",
     "example_post_id": 123}
  ],
  "anti_pattern": "чего делать НЕ стоит (пример из канала)",
  "explainer_posts": {
    "manifesto": 123, "best_guide": 456, "most_viral": 789
  }
}
```

Жёсткие правила промпта:
- `voice_quote` — только дословная выдержка из присланных текстов (никаких
  сочинительств); если подходящей цитаты нет — `null`.
- `explainer_posts` — только id из подборки; это не «топ по лайкам», а три
  роли: манифест канала / лучший гайд / самый вирусный.
- Никаких выдуманных ссылок на другие каналы для сравнения; вместо этого —
  архетип («личный блог практика с запусками инфопродукта»).
- Метрики интерпретировать с якорями (например, ER >3% — высокий, <1% — низкий).

## 5. Дальнейшие шаги по UX (на выбор)

- **Карточка + кнопки-раскрывашки.** Приходит только карточка, под ней кнопки
  «👤 Автор», «🧰 Что забрать», «🔥 Лучшие посты» — разделы подгружаются по тапу.
  Не пугает простынёй, читают то, что интересно.
- **Шеринг-картинка.** Генерировать картинку-«обложку» (канал, тир, слоган,
  шкалы) — её пересылают в другие чаты, это бесплатный рост. (v2)
- **«Сухой остаток».** Одним предложением: «если запомнить одно — то…».

## 6. Честность данных

- Глубина истории у нас ~100 последних постов, поэтому блок «история» честно
  называется «за последние недели», а не «за всё время». Настоящую хронологию
  развития даст Telethon-история и накопление срезов (v1 из бэклога).
- Похожесть на другие каналы и «похож на @X» не выдумываем.
