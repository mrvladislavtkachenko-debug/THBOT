# THBOT — бот для роста Telegram-канала 🤖🚀

Бот для **экспертного / обучающего канала**: приводит новых подписчиков через
проверку подписки + лид-магнит + реферальную программу с уровнями + рейтинг + рассылки.

## Как бот привлекает людей

| Механика | Как работает |
|---|---|
| 🎁 Лид-магнит за подписку | Человек заходит в бота → подписывается на канал → жмёт «Проверить» → получает подарок (чек-лист, гайд) |
| 👥 Рефералка с уровнями | 0 друзей = базовый подарок, 3 друга = гайд, 10 друзей = мини-курс/разбор. Уровни меняются в `.env` |
| 🏆 Рейтинг топ-10 | Соревнование: кто больше привёл. Топ-3 получают отдельный приз в конце месяца |
| 🛡 Анти-накрутка | Балл засчитывается, только если приглашённый **подписан на канал**. Отписался — балл сгорает. Сам себя пригласить нельзя |
| 📩 Рассылка | Прогрев базы: анонсы постов, эфиров, продуктов |
| 📊 Админка | `/stats` — статистика, `/export` — выгрузка CSV, `/broadcast` — рассылка |

**Воронка:** ссылка на бота → подписка на канал → подарок → «пригласи 3 друзей ради следующего» → рейтинг → прогрев рассылками.

## Быстрый запуск (10 минут)

### 1. Создай бота
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи **токен**.
2. Там же можно поставить описание и аватарку.

### 2. Подготовь канал
1. **Добавь бота в администраторы канала** (иначе проверка подписки не сработает!). Достаточно права «просмотр участников» — боту не нужны права на посты.
2. Узнай `CHANNEL_ID`: перешли любой пост из канала боту [@userinfobot](https://t.me/userinfobot) — он покажет ID вида `-100...`.
3. Узнай свой ID так же через [@userinfobot](https://t.me/userinfobot) — это `ADMIN_IDS`.

### 3. Запусти бота
```bash
cp .env.example .env
# открой .env и вставь BOT_TOKEN, CHANNEL_ID, CHANNEL_URL, ADMIN_IDS
nano .env   # или любым редактором

pip install -r requirements.txt
python bot.py
```

Увидишь `🤖 @твой_бот запущен` — готово ✅

### 4. Проверь механику сам
1. Напиши боту `/start` → подпишись на канал → «Проверить» → забери подарок.
2. С другого аккаунта перейди по своей реф-ссылке (`👥 Пригласить друзей`) → подпишись → первому аккаунту придёт «+1 друг».

## Настройка под себя

Всё меняется без кода:

- **`.env`** — токен, канал, админы, названия и ссылки подарков, пороги `REWARD_LEVELS`.
- **`texts.py`** — все тексты бота (приветствие, «как это работает», подарки). Перепиши под свою нишу.
- **`config.py`** — уровни по умолчанию `0, 3, 10`.

Идеи подарков для экспертного канала:
- уровень 0: чек-лист / подборка ошибок / шаблон;
- уровень 3: гайд / запись вебинара / библиотека промптов;
- уровень 10: мини-курс / личный разбор / созвон.

Подарки можно просто вести ссылкой на пост канала (`GIFT_URL_0` и т.д.) — тогда каждый, кто забирает подарок, ещё и смотрит канал 👀

## Команды

**Пользователь:** кнопки меню — 🎁 Мой подарок, 👥 Пригласить друзей, 🏆 Рейтинг, ℹ️ Как это работает.

**Админ:**
- `/admin` — помощь
- `/stats` — всего / подписаны / рефералов / за сутки
- `/top` — топ-10
- `/broadcast` — рассылка: ответь командой на сообщение, которое хочешь разослать, **или** отправь `/broadcast` и потом пришли текст/фото/видео. `/cancel` — отмена
- `/export` — CSV со всеми пользователями

## Как продвигать (план на первые 2 недели)

1. **День 1–2.** Закрепи в канале пост: «🎁 Забери чек-лист через нашего бота + получи гайд за 3 друзей» + кнопка на бота.
2. **День 3.** Лично разошли реф-ссылку 20–30 знакомым с текстом «забери мой бесплатный материал, тебе зайдёт».
3. **День 5.** Пост-кейс: «Вот что внутри подарка» (скриншоты) + напоминание про уровень за 3 друзей.
4. **День 7.** Опубликуй рейтинг топ-5 (скрин из бота) + анонс приза за топ-3 в конце месяца.
5. **День 10.** Рассылка через `/broadcast`: «Осталось 4 дня до розыгрыша, тебе не хватает N друзей».
6. **Постоянно:** ссылка на бота в описании канала, в конце каждого поста («🎁 все материалы — в закрепе через бота»), взаимопиар с каналами смежной тематики именно **ботом**, а не каналом (конверсия выше, т.к. есть подарок).

Главный принцип: люди идут не «в канал», а **за конкретной пользой + азартом**. Поэтому подарок должен решать одну боль за 15 минут, а следующий уровень — казаться достижимым (3 друга, а не 50).

## Структура проекта

```
bot.py        — вся логика (aiogram 3.x)
config.py     — настройки из .env
database.py   — SQLite (users + referrals)
keyboards.py  — кнопки
texts.py      — все тексты (редактируй смело)
.env.example  — шаблон настроек
```

База хранится в `bot.db` (не коммитится). Бэкап — просто скопируй файл.

## Частые проблемы

- **«Подписку не вижу», хотя подписан** → бот не админ канала. Добавь в администраторы и попробуй снова через 10 сек.
- **Канал приватный** → тоже работает, главное — бот в админах. `CHANNEL_URL` тогда = invite-ссылка.
- **Хочу сбросить базу** → останови бота, удали `bot.db`, запусти снова.
