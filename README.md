# THBOT

Telegram-бот: пользователь присылает ссылку на канал — бот возвращает сводку об авторе, развитии канала, полезном и бесполезном контенте и о том, какие практики можно забрать себе.

📄 Полное описание продукта и техническое ТЗ: [docs/bot-spec.md](docs/bot-spec.md)

## Кратко

- **Вход:** `t.me/username`, `@username`, ссылка-инвайт (v2) или пересланный пост.
- **Выход:** структурированный отчёт — автор, ниша, динамика развития, индекс полезности 0–100, топ полезных постов, «выносная польза» (практики/инструменты/форматы), красные флаги (реклама, накрутка), вердикт.
- **Как работает:** сбор постов (Telethon MTProto + fallback на веб `t.me/s/`) → предобработка → LLM-классификация постов (полезное/нейтральное/шум) → LLM-синтез отчёта.
- **Стек (план):** Python, aiogram 3, Telethon, PostgreSQL, Redis + arq, Docker.
