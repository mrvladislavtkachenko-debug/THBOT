# Запуск THBOT в VS Code — пошаговая инструкция

Бот написан на Python, не требует баз данных и серверов: всё работает на вашем
компьютере, нужны только два бесплатных ключа — токен Telegram-бота и ключ OpenRouter.

---

## 1. Что установить заранее

1. **Python 3.11 или новее** — https://www.python.org/downloads/
   - При установке на Windows поставьте галочку **«Add python.exe to PATH»**.
   - Проверка: в терминале `python --version` (Windows) или `python3 --version` (macOS/Linux).
2. **Visual Studio Code** — https://code.visualstudio.com/
3. В VS Code установите расширение **Python** (Microsoft):
   боковая панель Extensions (`Ctrl+Shift+X` / `Cmd+Shift+X`) → найдите «Python» → Install.
   (Оно же поставляет отладчик и автоматически находит виртуальное окружение.)

---

## 2. Распаковать и открыть проект

1. Распакуйте архив `thbot-mvp.zip` в любую папку.
2. В VS Code: **File → Open Folder…** → выберите распакованную папку `thbot-bot`.
3. Откройте терминал внутри VS Code: **Terminal → New Terminal**
   (`` Ctrl+` ``). Терминал откроется в корне проекта.

## 3. Создать виртуальное окружение и установить зависимости

В терминале VS Code (в корне проекта):

**Windows (PowerShell):**
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
Если при активации появляется ошибка про политику запуска скриптов — выполните один раз:
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```
и повторите активацию.

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

> Альтернатива без терминала: `Ctrl+Shift+P` → **Python: Create Environment…** →
> Venv → выбрать requirements.txt. VS Code сам всё создаст и установит.

После создания окружения выберите интерпретатор: `Ctrl+Shift+P` →
**Python: Select Interpreter** → вариант с `.venv`.

## 4. Получить два бесплатных ключа

1. **Токен Telegram-бота:**
   - откройте в Telegram [@BotFather](https://t.me/BotFather);
   - команда `/newbot`, задайте имя и username бота (username должен заканчиваться на `bot`);
   - BotFather пришлёт строку вида `123456:ABC-DEF...` — это и есть токен.

2. **Ключ OpenRouter (бесплатные ИИ-модели):**
   - зарегистрируйтесь на https://openrouter.ai (можно через GitHub, карта не нужна);
   - зайдите на https://openrouter.ai/keys → **Create Key** → скопируйте ключ
     (вида `sk-or-v1-...`).

## 5. Заполнить .env

1. Скопируйте файл `.env.example` и назовите копию `.env`
   (в терминале: `cp .env.example .env` на macOS/Linux;
   `copy .env.example .env` в Windows PowerShell… или просто продублируйте файл в проводнике).
2. Откройте `.env` и впишите ключи:

```env
BOT_TOKEN=123456:ABC-DEF...ваш-токен-от-BotFather
OPENROUTER_API_KEY=sk-or-v1-...ваш-ключ
```

Остальные строки в `.env` можно не трогать. Файл `.env` уже в `.gitignore` —
ключи не попадут в репозиторий.

## 6. Запустить бота

Любой из способов:

- **Кнопка F5** (или Run → Start Debugging) — конфигурация «THBOT: запустить бота»
  уже настроена в `.vscode/launch.json`;
- или в терминале (при активированном `.venv`):

```bash
python -m thbot.bot
```

Если всё хорошо, в терминале появится строка `THBOT запущен…`.
Остановить бота: `Ctrl+C` в терминале (или красный квадрат в панели отладки).

> Важно: не запускайте две копии бота с одним токеном одновременно —
> Telegram будет ругаться конфликтом polling.

## 7. Пользоваться

1. Откройте в Telegram своего бота (ссылку на него дал BotFather).
2. Команда `/start`.
3. Пришлите ссылку на публичный канал, например:
   `https://t.me/molyanov_blog` или `@molyanov_blog`.
   Можно также **переслать боту любой пост** из канала.
4. Бот напишет статусы («Собираю посты…», «Анализирую…») и через 1–2 минуты
   пришлёт сводку: автор, о чём канал, развитие, индекс полезности,
   «что забрать себе», лучшие посты и вердикт.

Повторный запрос того же канала в течение 7 дней берётся из кэша — мгновенно
и без расхода лимита OpenRouter.

---

## Проверка без ключей (только парсер)

Парсер каналов можно проверить отдельно, ещё до получения ключей:

```bash
python -m thbot.parser molyanov_blog --limit 20
```

(или F5 → конфигурация «THBOT: проверить парсер»). Команда выведет метаданные
канала и последние посты, собранные с `t.me/s/molyanov_blog`.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `BOT_TOKEN не задан` / `OPENROUTER_API_KEY не задан` | Файл `.env` не создан или ключи вписаны не туда. Проверьте, что `.env` лежит в корне проекта (рядом с `requirements.txt`) и в нём нет кавычек/пробелов вокруг значений. |
| `ModuleNotFoundError: No module named 'thbot'` | Запускайте именно `python -m thbot.bot` из **корня проекта** (а не открывая файл `bot.py` напрямую). |
| `Unauthorized` / `401` от Telegram | Неверный `BOT_TOKEN` — перепроверьте токен от BotFather. |
| Бот пишет «бесплатные ИИ-модели перегружены» | Это лимит/загрузка бесплатных моделей OpenRouter (429). Подождите 2–5 минут и нажмите «🔄 Обновить». Если повторяется — смените модели в `.env`: актуальный бесплатный список на https://openrouter.ai/models?max_price=0, модели указываются через запятую в `CLASSIFIER_MODELS` и `SYNTHESIS_MODELS`. |
| `Лимит свежих анализов исчерпан` | На бесплатном ключе ~50 запросов в день; в боте стоит лимит 5 свежих каналов в сутки на пользователя (повторные из кэша — без лимита). Лимит сбрасывается завтра (UTC). Разовое пополнение OpenRouter на $10 поднимает потолок до 1000 запросов/день. |
| «Канал не найден» | Канал приватный/не существует/это не канал, а чат или пользователь. MVP работает только с публичными каналами. |
| `python` не найден в терминале | Python не добавлен в PATH (переустановите с галочкой «Add to PATH») или используйте `python3`. |
| Бот работает, но не отвечает в Telegram | Проверьте, что печатает терминал; остановите другие копии бота с тем же токеном. |

## Где что лежит

```
thbot/
  config.py    — настройки (читает .env)
  parser.py    — сбор постов с t.me/s/<канал>
  analyzer.py  — вызовы ИИ (классификация + синтез) и расчёт метрик
  report.py    — текст отчёта
  storage.py   — локальный кэш в SQLite (файл thbot.db создастся сам)
  bot.py       — сам Telegram-бот
.env           — ваши ключи (создаёте сами, в архив его нет)
thbot.db       — кэш отчётов (создастся при первом запуске)
```
