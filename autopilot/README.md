# 🤖 THBOT Autopilot — подписчики без твоего участия

Полностью автоматическая схема (в отличие от реферального бота в корне репозитория):
ты один раз настраиваешь — дальше всё само.

## Как это приводит людей (почему это работает)

Главный бесплатный источник подписчиков в Telegram — **комментарии под крупными
каналами твоей ниши**. Человек читает пост у донора → видит твой умный коммент →
жмёт на имя → видит твой канал → подписывается.

Автопилот делает это 24/7 вместо тебя:

| Модуль | Что делает сам |
|---|---|
| 👀 Мониторинг доноров | Следит за 5–15 каналами ниши, ловит свежие посты |
| 💬 Автокомментинг | Ждёт 15–45 мин (как живой) и оставляет полезный коммент из ротации 8 шаблонов |
| 📝 Автопостинг | Ведёт твой канал по расписанию (09:00 / 13:00 / 19:00, посты из `posts.txt`) |
| 📊 Статистика | Замеряет подписчиков каждые 6 ч, шлёт отчёт в Избранное каждое утро |
| 🛡 Безопасность | Лимиты (6 комментов/день), активные часы, стоп-слова, тестовый режим, пауза одной командой |

**Реалистичные цифры:** 6 комментов/день × 30 дней = ~180 комментов. При среднем
охвате это 50–300 переходов в канал в месяц. Масштабируется добавлением доноров.

## Запуск (15 минут)

### 1. Получи API-доступ (5 мин)
1. Зайди на https://my.telegram.org → **API development tools** → создай приложение (название любое).
2. Запиши `API_ID` и `API_HASH`. Это НЕ токен бота — это доступ твоего аккаунта.

### 2. Настрой (5 мин)
```bash
cd autopilot
cp .env.example .env
nano .env
```
Заполни минимум: `API_ID`, `API_HASH`, `MY_CHANNEL`, `DONORS` (5–15 каналов твоей ниши через запятую).
Остальное можно не трогать. **`DRY_RUN=1` не меняй** — первые дни только тест.

Приготовь контент:
```bash
cp posts.txt.example posts.txt   # и напиши 10–30 постов (разделитель ---)
# comments.txt уже готов (8 шаблонов) — перепиши 2–3 под свою нишу
```

### 3. Первый запуск (5 мин)
```bash
pip install -r requirements.txt
python autopilot.py
```
Первый раз попросит **телефон + код из Telegram** (приходит в приложение).
Создастся файл сессии — дальше вход без кода.

### 4. Тест 2–3 дня
Смотри `autopilot.log`: там строки `🧪 DRY: @донор post ...` — так выглядели бы
комменты. Подправь шаблоны и доноров. Команды себе в Избранное:
`/stat` — что происходит прямо сейчас.

### 5. Боевой режим
Себе в Избранное: `/dry off`. Всё — дальше автопилот работает сам.
Каждое утро в 09:30 приходит отчёт: подписчики, динамика, комменты.

## Управление (пишешь себе в Избранное)

- `/stat` — комменты + подписчики + режим
- `/pause` / `/resume` — пауза / продолжить
- `/dry on` / `/dry off` — тестовый / боевой режим
- `/reset_queue` — начать автопосты с первого (после пополнения `posts.txt`)

## Как выбрать доноров (важно!)

- Твоя ниша или смежная, **с включёнными комментариями** (иначе комментировать некуда).
- От 5 тыс. подписчиков, живые комменты под постами (10+).
- 5–15 штук: 3 крупных (охват) + остальные средние (там тебя заметнее).
- Не комментируй у прямых конкурентов-врагов — только дружелюбные ниши.

## Правила безопасности (прочти!)

1. **Неделю 1:** лимиты по умолчанию (6/день). Не увеличивай — свежие аккаунты с активностью банят.
2. **Комменты без ссылок.** Ссылки трут админы и за них прилетают жалобы. Люди переходят по имени автора.
3. **Комментируй от имени канала** (`SEND_AS=@твой_канал`) — тогда переход в 1 клик. Нужны права админа своего канала.
4. **Шаблоны — живые.** Перепиши `comments.txt` своими словами, добавляй новые — одинаковые комменты палят автоматизацию.
5. Аккаунту должно быть **больше месяца**, с аватаркой и именем — «пустые» аккаунты банят чаще.
6. Это автоматизация клиентского API: формально против правил Telegram. Лимиты и «человеческие» задержки снижают риск до минимума, но стопроцентной гарантии нет — не вешай это на свой единственный аккаунт, заведи отдельный рабочий.

## Чего автопилот НЕ делает (и почему)

- ❌ **Рассылка в личку незнакомцам / автоинвайт в канал.** В канал добавить никого нельзя технически (только в группы), а спам в ЛС = смерть аккаунта за 1–2 дня + нулевое качество подписчиков. Поэтому такого модуля здесь нет осознанно.
- ❌ **Накрутка ботов.** Цифры красивые, охватов ноль, канал убивается. Не делаем.
- ❌ **Волшебная кнопка «1000 подписчиков за ночь».** Её не существует. Есть система: комменты + контент + замеры. Она и собрана.

## Файлы

```
.env.example  — настройки
config.py     — чтение .env
autopilot.py  — ядро (мониторинг, комменты, посты, отчёты)
storage.py    — SQLite: лог, подписки, состояние
templates.py  — шаблоны, ротация, фильтры
comments.txt  — 8 шаблонов комментариев (редактируй!)
posts.txt.example → posts.txt — очередь автопостов
```

## Масштабирование (когда пойдёт)

1. Добавь доноров до 15.
2. Подними лимит до 8–10/день (со 2-й недели).
3. Веди 30 постов в очереди + дублируй лучшие посты в 2–3 дружественных чата вручную.
4. Второй аккаунт = второй автопилот с другими донорами (другой `SESSION_NAME`).
5. Платно ускорь: посевы в 2–3 каналах-донорах (пост с кнопкой на твой канал) — замер эффекта увидишь в утреннем отчёте.
